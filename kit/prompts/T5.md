Separate chart data from chart rendering in `DashboardComponent`.

Requirements:
1. Add an exported interface `ChartData` with `labels: string[]` and `series: number[][]`.
2. Add three public methods `getDailySalesData(): ChartData`, `getCompletedTasksData(): ChartData`, and `getWebsiteViewsData(): ChartData` that return exactly the label and series values that are currently defined inline in `ngOnInit`.
3. Add a public method `suggestedHigh(series: number[][]): number` that returns the smallest multiple of 10 that is strictly greater than the largest value in all series (for example 38 gives 40, 750 gives 760, 895 gives 900).
4. Use the three data methods in `ngOnInit` and pass `suggestedHigh(...)` as the `high` option of each chart instead of the hard-coded 50 and 1000.

Do not change any other component, module, or shared file.
