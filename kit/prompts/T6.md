Improve the page title handling in `NavbarComponent` and show a breadcrumb.

Requirements:
1. Add a public method `resolveTitle(path: string): string` that returns the `title` of the entry in `ROUTES` whose `path` matches. Before matching, normalise the input: drop a leading `#`, drop a query string (`?...`) and a fragment (`#...`), and drop a trailing slash (but keep `/` itself). If nothing matches, return `'Dashboard'`. The method must work without `ngOnInit` having run.
2. Change `getTitle()` so that it delegates to `resolveTitle` with the current location path. Today `/table-list?tab=2` yields `'Dashboard'`; afterwards it must yield `'Table List'`.
3. Add an `@Input()` property `brandTitle: string` with the default value `'Material Dashboard'` and a public getter `breadcrumb: string` that returns `` `${brandTitle} › ${getTitle()}` `` (the separator is the single character `›`, U+203A, with one space on each side).
4. Make `sidebarVisible` a public property (it is private today) and bind the class `toggled` of the `navbar-toggler` button in the template to it.
5. In the template, show `{{ breadcrumb }}` in the `navbar-brand` link instead of `{{getTitle()}}`.

Do not change `ROUTES`, do not change `SidebarComponent`, and do not change any other component, module, or shared file. Do not add dependencies.
