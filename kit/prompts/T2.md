Add a menu filter to `SidebarComponent`.

Requirements:
1. Add a public method `filterMenu(query: string): void`. It sets `menuItems` to all entries of `ROUTES` whose `title` contains `query`, compared case-insensitively. An empty string or a string that only contains whitespace restores the full list.
2. Add a public property `activeFilter: string` that always holds the last query that was applied (trimmed).
3. Add a text input above the navigation list in the template that calls `filterMenu` on every `input` event.

Do not change `ROUTES` and do not change any other component, module, or shared file.
